## 2026-09-21: Claude Code login failure in the devcontainer [Claude Code]
1. Symptom: Claude Code (VS Code extension 2.1.278 inside the container) could not log in; the third attempt showed HTTP 400. Extension log: two browser logins succeeded server-side, then `Failed to save OAuth tokens: EACCES mkdir /home/node/.claude/.storage-write.lock`; the manually pasted code was already consumed, hence 400.
2. Root cause: the named volume `remotion-harness-claude-home` was created root-owned and empty; the `sudo chown` in `postCreateCommand` failed silently because `node:22-bookworm-slim` has no `sudo`.
3. Fix: volume chowned to 1000:1000; Dockerfile installs `sudo` (NOPASSWD for node) and pre-creates `/home/node/.claude` owned by node; `postCreateCommand` now prints a warning instead of swallowing the error. Container rebuild required; learning recorded in 81.
